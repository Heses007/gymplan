# Gym Plan

Persoonlijke fitness-app: 5-daags schema (ma–vr), gewichten bijhouden, AH-voedingsplan, boodschappenlijst en aanbiedingen van AH en Dirk.

Open de app: https://heses007.github.io/gymplan/

Op je iPhone: open de link in Safari → deelknop → **Zet op beginscherm**.
Je gegevens worden alleen op je eigen telefoon bewaard. Maak af en toe een backup via je profiel.
